# 專案總覽

## 簡介

Deep Search Agent 是一個**無框架（framework-free）**的深度搜尋 AI 代理實作，能夠透過多輪搜尋與反思（reflection）機制，自動產生高品質的研究報告。專案完全從零打造，不依賴 LangChain、LlamaIndex 等重型框架。

## 核心功能

- **無框架設計**：所有邏輯皆為原生 Python 實作，便於理解與客製化
- **多 LLM 支援**：內建 DeepSeek 與 OpenAI 兩種後端，可透過繼承 `BaseLLM` 輕鬆擴充
- **智慧搜尋**：整合 Tavily Search API，提供高品質網路搜尋
- **反思機制**：多輪反思迴圈，持續補充遺漏資訊，確保研究深度
- **狀態管理**：完整的研究過程狀態追蹤，支援序列化 / 反序列化（JSON）
- **Web 介面**：提供 Streamlit 圖形化操作介面
- **Markdown 輸出**：自動產生格式美觀的 Markdown 研究報告

## 快速啟動

### 1. 安裝依賴

```bash
pip install -r requirements.txt
```

### 2. 設定 API 金鑰

編輯根目錄 `config.py`：

```python
DEEPSEEK_API_KEY = "your_deepseek_api_key_here"
TAVILY_API_KEY = "your_tavily_api_key_here"
# OpenAI（選用）
OPENAI_API_KEY = "your_openai_api_key_here"
```

### 3. 執行範例

```bash
# 基本範例
python examples/basic_usage.py

# Web 介面
streamlit run examples/streamlit_app.py
```

### 4. 程式碼呼叫

```python
from src import DeepSearchAgent, load_config

config = load_config()
agent = DeepSearchAgent(config)
report = agent.research("2025年人工智慧發展趨勢")
print(report)
```
